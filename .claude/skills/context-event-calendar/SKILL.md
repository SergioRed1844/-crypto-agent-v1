# Context event calendar (3 years, refreshed every 15 days)

**Golden rule: never invent a date.** Every curated event carries `source_url`. If an official schedule is not
published, the date is an *estimate* (`status: scheduled_estimate`, `date_precision: month`) generated by rule,
and it can never trigger a blackout.

## Files (`data/context/`)
- `sources/calendar_curated.json` — verified forward events (central banks, US data, elections + GDP share,
  crypto/AI regulation, Mt. Gox/government supply, halving). Edited by hand or by promoting proposals.
- `sources/calendar_proposed.json` — unverified candidates from the news classifier and the Gemini+Google Search
  coverage audit. Shown as "propuesto (revisar)"; P(occur)=0.5; never blackout.
- `sources/history_events.json` — realized events 2009→today (curated) used by the event study and as "recent".
- `sources/gdp_shares.json` — IMF WEO shares (elections are weighted by economic size).
- Generated: `calendar.json` (curated + rules + proposals, normalized to UTC), `CALENDARIO.md` (GitHub view).

## Schema (`app/context/schema.py`, enforced by `normalize()`)
`id, date (YYYY-MM-DD), time_local + tz (IANA) or null, date_precision exact|day|month|quarter|year,
status confirmed|scheduled_estimate|expected|speculative|happened|proposed, category (closed list of 18),
subcategory, country (ISO-2 | EU | GLOBAL), title_es, why_es, crypto_stance pro|anti|neutral|uncertain,
prior_tier 1–5, source_url, source_title, origin`. Store UTC (`utc` is computed, DST-correct via zoneinfo);
display in America/Monterrey (UTC−6). FOMC 14:00 ET = 18:00Z in summer, 19:00Z in winter — tested.

Categories: MONETARY_POLICY, MACRO_DATA, FISCAL, TRADE, ELECTION, GOV_TRANSITION, CRYPTO_REGULATION,
TECH_AI_REGULATION, PATENT_LICENSE, CRYPTO_STRUCTURAL, CRYPTO_SUPPLY, INSTITUTIONAL_ADOPTION, GEOPOLITICAL,
FINANCIAL_CRISIS, HACK_SECURITY, ONCHAIN_WHALE, PANDEMIC_HEALTH, DERIVATIVES_EXPIRY.
Direction source per category: `stance` (known when it happens) vs `surprise` (FOMC/CPI: only after the print).

## Rule-generated events (`recurring.py`)
Deribit monthly/quarterly expiries (last Friday 08:00 UTC), CME monthly (last Friday 16:00 London), and
estimates for FOMC (8/yr pattern), CPI (mid-month), NFP (first Friday), Jackson Hole — ONLY for months after the
last official date in the curated file. When the Fed/BLS publishes, add the official dates to curated and the
estimates disappear automatically.

## Biweekly refresh (`python -m app.context.pipeline refresh`, GitHub Actions days 1 and 15)
1. News 15 d (CryptoPanic v2 if the key works, GDELT always) → classifier → realized events (`news_events.json`)
   + future dates as proposals. 2. Coverage audit: Gemini with Google Search lists scheduled events missing from
   the calendar → proposals. 3. Macro moderators → `macro.json`. 4. Event study → `weights.json`.
   5. Rebuild calendar + signal + views; mirror to Google Sheets if `SHEETS_WEBAPP_URL`.

## Promoting a proposal (human or Claude in a session)
Open the proposal's `source_url`, confirm the date on a primary/reputable source, then move the event to
`calendar_curated.json` with `status: confirmed` (or `expected`), the real `source_url`, and `origin: "curado-<fecha>"`.
Run `python -m app.context.pipeline calendar` and `python -m tests.test_context`.

## Coverage checklist (what "complete" means)
Fed + ECB + BoJ + BoE + Banxico decisions; US CPI, NFP, PCE, GDP; US funding/debt-limit deadlines; tariff
deadlines; national elections of every country ≥1% of world GDP + crypto-relevant ones (AR, TR, NG, VN, PH, PK,
SV, UA, TH, AE) and inaugurations; GENIUS/CLARITY/MiCA/AMLR/FCA milestones; ETF deadlines; Mt. Gox/FTX/government
coin movements; halving; major protocol upgrades; option expiries. `event_calendar.coverage()` lists gaps.
